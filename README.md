## Featured Projects

### AMSL Broker Platform

Utility brokerage software supporting quotation workflows, contract management, commission tracking, supplier pricing matrices, and customer lifecycle management.

### AUC Debt Recovery System

Debt recovery platform featuring account assignment, site visit execution, payment tracking, recovery workflows, and operational reporting.

### TRK Finance Software

Loan management platform supporting customer onboarding, document verification, EMI tracking, investor allocation, repayment management, and financial reporting.

### Accounting Management System

Accounting software for inventory management, supplier purchasing, invoicing, reconciliation, and financial record keeping.

## Local Development

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Start production server:

```bash
npm start
```
